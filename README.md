# CareerPilot

Multi-Agent AI Career Intelligence Platform — an AI-powered career guidance companion.

## Overview

CareerPilot orchestrates a team of specialized AI agents to help students plan their careers:

- **Career Vision** — build a long-term career roadmap
- **Career Drift** — detect when you're drifting from your goals
- **Skill Intelligence** — assess and map your skills
- **Career Evidence** — verify claimed skills against your projects
- **Opportunity Discovery** — find matching jobs and roles
- **Interview Readiness** — practice and prepare for interviews
- **Career Health** — track overall career fitness

## Tech Stack

- **Backend:** Python 3.11, FastAPI
- **Orchestration:** LangGraph, Redis
- **Data:** Neo4j (knowledge graph), ChromaDB (vector store)
- **LLM:** Groq API

## Branching Model

- `main` — production-ready code
- `dev` — integration branch (feature branches merge here)
- `feature/*` — personal/feature branches for each team member
